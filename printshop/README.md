# Printshop

A vendor site for personalized stationery whose product page registers its tools on `document.modelContext` and whose server answers the same tools over HTTP, so an organizer's agent (Gather's) quotes, orders, and follows a batch of cards with a name on each. The specification is `docs/prd.md` (local). One workspace of the [WebMCP sandbox](../README.md) on port 3114. The Designs, Design, and Batch pages sit over the design and shop rows in `src/data/`; `npm run test:webmcp -w printshop` runs the Playwright suites and `npm run test:demo -w printshop` records the Gather-to-print-shop demo.
