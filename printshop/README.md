# Printshop

A vendor site for personalized stationery whose product page registers its tools on `document.modelContext` and whose server answers the same tools over HTTP, so an organizer's agent (Gather's) quotes, orders, and follows a batch of cards with a name on each. The specification is `docs/prd.md` (local). Scaffolded from `app-template` on port 3114; the notes page is the placeholder until the first ticket lands.
